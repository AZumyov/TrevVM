# Contributing😄

Contributions are welcome when they improve reliability, documentation, or accessibility.
## Before contributing🤔

1. Read the repository README, `SECURITY.md`, and `LICENSE`.
2. Open an issue or discussion for substantial changes.
3. Do not submit credentials, personal data, copyrighted installers, or proprietary assets.
4. Keep changes focused and explain their operational and security impact.

## Documentation changes✍️

Prefer clear, reproducible instructions. Identify the affected file, host assumptions, required privileges, network dependencies, and rollback steps.
## Pull requests🫵

A useful pull request includes:

- A concise summary and motivation.
- Testing performed, including the host and Docker environment.
- Any changes to ports, privileges, downloads, persistence, or third-party software.
- Screenshots or logs when they clarify a UI or runtime change.
